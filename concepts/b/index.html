Foundation / Git objects

Git은 파일이 아닌 관계를 기억한다

처음 Git을 배우면 add, commit, push의 순서를 외우게 된다. 하지만 명령어 뒤에는 서로를 가리키는 네 종류의 객체가 있다.

blob은 파일의 내용을, tree는 디렉터리 구조를 표현한다. commit은 하나의 tree와 이전 commit을 가리킨다. branch는 그중 한 commit을 가리키는 움직이는 이름이다.

차이가 아닌 스냅샷

각 커밋을 변경사항 묶음으로 이해할 수도 있지만 Git의 저장 모델은 스냅샷에 가깝다. 동일한 내용은 같은 객체를 다시 가리키므로 불필요한 중복이 생기지 않는다.

내용이 곧 주소가 된다

객체의 이름은 내용을 바탕으로 계산된다. 내용이 같다면 언제 어디에서 만들었든 같은 식별자를 얻는다. 이 성질이 기록의 무결성과 분산 저장을 가능하게 한다.
