Local과 Remote의 관계

  • Local은 작업 중인 commit과 branch를 보관하는 내 컴퓨터의 저장소다.
  • Remote는 협업과 백업을 위해 네트워크 또는 다른 경로에 둔 저장소다. GitHub는 Remote를 제공하는 서비스 중 하나다.
  • Local의 새 commit은 git push를 실행하기 전까지 Remote에 반영되지 않는다.
  • git fetch는 Remote의 최신 이력을 내려받아 Local의 remote-tracking branch를 갱신한다. working tree를 자동으로 바꾸지는 않는다.

Remote 등록 문법

bash · syntax
$ git remote add <name> <remote-url>

<name>은 Local에서 사용할 Remote의 별칭이다. 첫 Remote의 이름은 관례적으로 origin을 사용한다.

Remote 등록 예시

bash · example
$ git remote add origin https://github.com/user/repository.git

등록 정보 확인

bash · command
$ git remote -v
origin  https://github.com/user/repository.git (fetch)
origin  https://github.com/user/repository.git (push)

fetch와 push URL을 각각 지정할 수 있기 때문에 두 줄로 표시된다.
