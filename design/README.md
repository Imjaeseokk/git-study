# Git Study 디자인 기준

이 디렉터리는 향후 Git 학습 페이지를 만들 때 사용하는 고정 디자인 기준입니다.

## 선택된 방향

**Quiet Index(A안)**를 기본 테마로 사용한다.

- Monotonomo의 따뜻한 모노톤과 인쇄물 같은 여백
- Craig Mod의 출판물형 콘텐츠 구조
- Aresluna의 필요할 때만 열리는 INDEX 렌즈
- 큰 제목, 비대칭 여백, 번호가 붙은 챕터 행
- 일반적인 고정 좌측 메뉴와 카드형 대시보드는 사용하지 않는다.

화면을 설명하는 홍보성·감성적 문구는 두지 않는다. 홈에서는 학습 영역과 노트 제목이 바로 보이게 한다.

## 보존할 색상 팔레트

| 역할 | 토큰 | 색상 |
|---|---|---|
| 종이 배경 | `--mono-paper` | `#F5F2ED` |
| 기본 먹색 | `--mono-ink` | `#1B1B1B` |
| 구분선 | `--mono-line` | `#D1CCC6` |
| 보조 문구 | `--mono-muted` | `#6C6762` |
| 흐린 UI | `--mono-soft` | `#AFABA7` |
| 중간 UI | `--mono-mid` | `#8C8782` |

실제 CSS 변수는 [theme-tokens.css](./theme-tokens.css)에 정의되어 있다. 향후 HTML 페이지는 이 파일을 불러오거나 동일한 토큰을 유지한다.

## 메타데이터 규칙

홈 화면에는 `Updated`, `Edition` 등의 사이트 메타데이터를 표시하지 않는다.

각 노트에는 다음 두 항목만 작게 표시한다.

```text
REVISION 03
LAST EDITED 14:32
```

- `REVISION`: 해당 노트의 수정 횟수
- `LAST EDITED`: 해당 노트의 마지막 수정 시각
- 공개용 저자 소개, 포트폴리오 설명, 발행 정보는 추가하지 않는다.

## 노트 제작 규칙

사용자가 공부한 텍스트와 그림을 제공하면 다음 구조로 관리한다.

- 노트별 독립 HTML 페이지
- 공통 테마 토큰과 레이아웃 CSS 재사용
- 그림은 저장소의 `assets/` 아래에 보관
- 페이지 전용 애니메이션은 해당 노트의 CSS 또는 JS 모듈로 분리
- INDEX 렌즈의 목차 항목과 홈의 노트 개수를 함께 갱신
- 모바일, 키보드 탐색, `prefers-reduced-motion`을 지원
- GIF가 꼭 필요한 경우를 제외하면 선명도와 용량을 위해 CSS, SVG 또는 Canvas 애니메이션을 우선 사용

## 보관된 다른 방향

Marginal Archive(B안)는 선택되지 않았지만 여백 주석, 관련 문서 연결, 지식 구조 표현이 필요한 개별 노트에서 일부 요소를 가져올 수 있다.
