# Git Study 디자인 기준

이 디렉터리는 향후 Git 학습 페이지를 만들 때 사용하는 고정 디자인 기준입니다.

## 기본 방향

- 주 레퍼런스: [Monotonomo](https://ondisplay.website/site/monotonomo)
- 인상: 따뜻한 종이, 먹색 활자, 조용한 인쇄물, 넓은 여백
- 색보다 타이포그래피·간격·얇은 선으로 정보 계층을 만든다.
- 일반적인 고정 좌측 메뉴와 카드형 대시보드는 사용하지 않는다.
- 목차는 읽기를 방해하지 않으면서 언제든 열 수 있어야 한다.
- Git의 커밋·브랜치·수정 기록은 출판물의 판·개정·주석처럼 표현한다.

## 보존할 색상 팔레트

| 역할 | 토큰 | 색상 |
|---|---|---|
| 종이 배경 | `--mono-paper` | `#F5F2ED` |
| 기본 먹색 | `--mono-ink` | `#1B1B1B` |
| 구분선 | `--mono-line` | `#D1CCC6` |
| 보조 문구 | `--mono-muted` | `#6C6762` |
| 흐린 UI | `--mono-soft` | `#AFABA7` |
| 중간 UI | `--mono-mid` | `#8C8782` |

실제 CSS 변수는 [theme-tokens.css](./theme-tokens.css)에 정의되어 있다. 향후 HTML 페이지는 이 파일을 불러오거나 동일한 토큰을 유지한다.

## 후보 A — Quiet Index

Monotonomo를 중심으로 Craig Mod의 출판물 구조와 Aresluna의 렌즈형 목차를 결합한다.

- 홈을 잡지 표지와 전체 목차의 중간 형태로 구성
- 큰 제목과 비대칭 여백
- 번호가 붙은 챕터 행
- 화면 우측의 작은 INDEX 렌즈를 누르면 목차가 펼쳐짐
- 수정 정보는 책의 판권지처럼 작게 표기

## 후보 B — Marginal Archive

Monotonomo를 중심으로 Gwern의 지식 연결성과 Cameron의 문헌·개정 표현을 결합한다.

- 본문을 중앙에 두고 주변 여백을 주석 공간으로 사용
- 태그보다 관련 개념과 선후 학습 경로를 표시
- 하단의 얇은 목차 스트립으로 현재 위치 표현
- 커밋 SHA, 마지막 수정일, 관련 문서를 문헌 메타데이터처럼 노출
- 정보량은 많지만 색과 박스 사용을 억제해 차분함 유지
